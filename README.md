# 👁️‍🗨️ OpenCV: The Open Source Computer Vision Library

Welcome to **OpenCV** – the leading open-source library for real-time computer vision, machine learning, and image processing. With its wide range of modules and cross-platform support, OpenCV empowers developers, researchers, and engineers to build cutting-edge AI-powered applications in fields like robotics, autonomous driving, AR/VR, surveillance, and biomedical analysis.

## 🤝 Contributing to OpenCV

We thrive thanks to contributions from developers around the globe. Whether it's code, documentation, or testing — every contribution matters.

🔍 **Before you begin**, please take a moment to read the [Contribution Guidelines](https://github.com/opencv/opencv/wiki/How_to_contribute) to ensure a smooth and successful process.

### 📌 Contribution Checklist

* 📎 Create one pull request per topic or issue.
* 🌿 Always target the correct base branch (check the guidelines).
* ✅ Include relevant test cases and update documentation when applicable.
* 🧹 Clean up intermediate or "oops" commits before opening your PR.
* 🎯 Adhere to our [coding conventions](https://github.com/opencv/opencv/wiki/Coding_Style_Guide) and style guides.

📖 See also:

* [How to Contribute (Wiki)](https://github.com/opencv/opencv/wiki/How_to_contribute)
* [Coding Style Guide](https://github.com/opencv/opencv/wiki/Coding_Style_Guide)
